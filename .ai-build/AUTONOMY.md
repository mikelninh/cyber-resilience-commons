# AUTONOMY

## Agents may autonomously
- Refactor deterministic simulator code without changing truth boundaries.
- Add tests and golden cases.
- Improve copy, accessibility, responsive layout, and documentation.
- Add new synthetic organization templates and incident scenarios when clearly labeled synthetic.
- Improve brief generation and planning guidance.

## Agents must not autonomously
- Add real-target scanning, probing, credential testing, exploitation, or enumeration.
- Add telemetry or send user-entered organization data to a server.
- Claim a real organization is vulnerable, secure, compliant, or certified from this simulator.
- Add probabilistic breach/loss estimates without an explicit evidence and calibration design.
- Add a generic security score.
- Publish sensitive operational details about a real target.

## Requires explicit project decision
- Any backend or account system.
- Any connector to real organization assets.
- Any authorized runtime validation mode.
- Any external data collection or analytics.
- Any change to licensing or project governance.
