# SPEC

## Product
Cyber Resilience Commons v1

## User promise
Help a non-specialist understand how a cyber incident could spread through a synthetic organization model, which defensive boundary changes the modeled outcome, and what to verify next in an owned or explicitly authorized environment.

## V1 capabilities
- Choose City, Hospital, School, NGO, or Small Business template.
- Customize organization name, identity count, one critical service, and one sensitive-data category.
- Run five synthetic incident scenarios.
- Toggle eight defensive boundaries.
- Display step-by-step containment path and modeled impact.
- Rank missing controls by modeled impact reduction across scenarios.
- Explain how each recommended control could be proven.
- Show recovery planning assumptions.
- Download/print a resilience brief.
- Run entirely client-side as a static app.

## Explicit non-goals
- Vulnerability scanner.
- Penetration test.
- Real-target reconnaissance.
- Compliance certification.
- Prediction of real loss, breach probability, or exact attack outcomes.
- Generic security score.

## Truth boundary
All incident and impact values are synthetic planning assumptions. A toggle means “assume this boundary works,” not “this control has been verified.” Real proof requires testing in an environment the tester owns or is explicitly authorized to assess.
