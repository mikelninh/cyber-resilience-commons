# Changelog

## 0.2.0 — guided tabletop drill

- Added a 15–30 minute browser-local team tabletop exercise.
- Added practical incident-response roles: incident lead, IT/security, operations, communications, privacy/legal.
- Added one-at-a-time incident injects derived from the same synthetic scenario model.
- Added local decision logging and ownership prompts.
- Added downloadable after-action review with facilitator reflections and evidence questions.
- Added deterministic tabletop golden cases and public safety gates.
- Made the team drill a first-class path from the main simulator.

- Standalone Cyber Resilience Commons repository.
- Five synthetic organization templates.
- Five incident scenarios.
- Eight defensive boundaries.
- Deterministic containment and modeled blast-radius engine.
- Custom organization assumptions kept in the browser.
- Prioritized missing-boundary recommendations.
- “How could we prove it?” guidance.
- Recovery drill assumptions.
- Downloadable/printable resilience brief.
- Deterministic golden-case tests.
