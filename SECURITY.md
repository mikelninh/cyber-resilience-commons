# Security Policy

## Scope
Cyber Resilience Commons v1 is a static, browser-local synthetic planning application. It is not intended to connect to, scan, probe, or attack real infrastructure.

## Reporting a vulnerability
Please report vulnerabilities in this repository privately to the maintainer rather than publishing exploit details immediately when doing so could expose users.

## Public-interest safety boundary
Reports about third-party systems are outside this repository's vulnerability-reporting scope. Do not use the Commons to test systems without authorization.

## Data handling
V1 has no backend and intentionally sends no organization customization data to a project server. A future change that introduces network submission, telemetry, accounts, or storage requires an explicit architecture and privacy review.
