# Public v1

## Definition of useful
A user with no specialist security background should be able to:
1. choose a recognizable organization type;
2. understand the incident assumption in plain language;
3. see the incident advance step by step;
4. see exactly which enabled boundary stops it;
5. compare the same incident before and after a change;
6. get no more than a few high-leverage next actions;
7. understand how to turn a planning assumption into evidence;
8. leave with a brief they can discuss with leadership or an IT/security provider.

## Definition of safe
The app must remain useful without requiring any real target, credential, IP address, domain, repository, or system connection.
