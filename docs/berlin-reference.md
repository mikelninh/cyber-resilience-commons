# Berlin reference context

Berlin is a motivation for the first synthetic city scenario, not a modeled target.

The Commons must never imply that its synthetic assets, control states, attack paths, impact values, or recovery assumptions describe Berlin's real internal environment. Public incident reporting can motivate scenario classes such as credential theft, lateral movement, ransomware, bulk exfiltration, vendor compromise, and session/token abuse. The actual city template remains invented and reusable by any municipality.

This separation is deliberate: the public-interest value is teaching resilience patterns and helping organizations prepare safely, not speculating about a real victim's internal weaknesses.
