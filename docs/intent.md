# Intent

## Mission
Make cyber resilience understandable and actionable for organizations that do not have a large security team.

## Primary user
A city, hospital, school, nonprofit, or small organization leader who needs to understand blast radius, priorities, and recovery without learning security jargon first.

## Core question
> If one account, device, vendor, or cloud session is compromised, how far could the incident spread — and what should we fix first?

## Public-interest principle
The Commons should reduce the expertise and budget required to rehearse resilience. Strong defensive patterns should be reusable and openly inspectable.

## Success
A non-specialist can configure a synthetic organization, run an incident, understand where it stops, identify the highest-leverage missing boundary, and leave with a concrete validation/recovery plan.
