# Constraints

1. **Synthetic by default.** No real organization topology or hidden infrastructure is represented.
2. **No unauthorized testing.** The project must not scan, exploit, probe, or alter third-party systems.
3. **No false certainty.** Avoid universal security scores and claims such as “secure” or “safe.”
4. **Explain assumptions.** Modeled blast-radius numbers are planning aids, not forecasts.
5. **Evidence before claims.** Real control validation must come from owned or explicitly authorized environments.
6. **Privacy first.** Public v1 runs entirely in the browser and requires no user account or server-side storage.
7. **Accessible language.** Security concepts must be understandable to leaders and general staff, not only specialists.
8. **Open patterns.** Defensive lessons should be reusable across municipalities and resource-constrained organizations.
