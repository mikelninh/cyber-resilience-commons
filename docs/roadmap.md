# Roadmap

## v1 — Understand blast radius
Synthetic organization templates, incident scenarios, controls, before/after containment, priorities, recovery assumptions, and resilience brief.

## v1.1 — Guided tabletop exercise
- facilitator mode;
- participant roles;
- timed incident injects;
- decision log;
- containment/recovery timer;
- after-action report;
- recurring drill cadence.

## v1.2 — Organization map
- simple identity/service/data/vendor dependency graph;
- criticality and owner assignment;
- unknown-owner / unknown-dependency gaps;
- scenario traversal over the user-created synthetic map.

## v1.3 — Evidence planner
For each claimed control, define a safe verification packet: owner, expected behavior, authorized test, evidence to retain, last-tested date, and retest trigger.

## Later — Commons knowledge layer
Aggregate only opt-in/anonymized defensive lessons and public guidance to show recurring safe patterns across municipalities and public-interest organizations. Never publish sensitive target details.
